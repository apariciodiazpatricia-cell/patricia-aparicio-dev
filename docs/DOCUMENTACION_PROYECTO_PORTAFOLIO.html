1. Resumen Ejecutivo y Ficha Técnica

Esta plataforma web representa el portafolio profesional interactivo de Patri Aparicio, concebido para ofrecer una experiencia inmersiva con temática Matrix Cyberpunk, rendimiento optimizado y un asistente conversacional dotado de Inteligencia Artificial (Google Gemini 2.5 Flash).

Propósito Principal: Demostrar competencias sólidas en desarrollo Frontend con React 19, maquetación responsiva con Tailwind CSS, diseño UI/UX en Figma & Stitch, consumo de APIs REST y testing automatizado con Vitest.

2.1 Gestión de Estado Global con Context API (CvContext.jsx)

  • Sincronización del CV: Lee el archivo patri-aparicio-cv.pdf y mantiene en memoria la transcripción exacta de la trayectoria, formación y habilidades de Patri.
  • Persistencia Local: Emplea localStorage para mantener la sesión del usuario activa.
  • Inyección Dinámica en IA: Cualquier consulta realizada a través del asistente chatbot inyecta el contenido del CV como contexto inmutable para evitar alucinaciones en el modelo.

2.2 Principios de Rendimiento y Aceleración por Hardware

  • Cero bloqueo del hilo principal: El efecto de lluvia digital Matrix y la animación de láser HUD corren acelerados por GPU mediante CSS Keyframes y Canvas API.
  • Vídeos Ligeros: Los clips de demostración utilizan atributos muted, loop, playsInline y precarga controlada para garantizar tiempos de carga inferiores a 1 segundo.
  • Seguridad de Credenciales: Las claves secretas de Google Gemini residen de forma estricta en el servidor backend (server/.env) y nunca se compilan en los ficheros del cliente.

3. Catálogo Completo de Componentes UI

3.1 NavbarPacman.jsx

Barra de navegación superior fija (fixed top-0 inset-x-0 z-50) que incorpora una pista animada de Pac-Man interactiva. Cuenta con observador de scroll dinámico que detecta la sección visible en tiempo real y botón de acceso rápido al asistente virtual.

3.2 Hero.jsx

Cabecera principal de alto impacto visual. Incorpora:

  • Efecto de máquina de escribir (Typewriter) para el título profesional.
  • Avatar holográfico táctico con scanlines CRT, barrido láser HUD y marcadores perimetrales.
  • Widgets embebidos de clima en tiempo real (WeatherWidget) y frases técnicas para desarrolladores (ApiWidget).

3.3 HeroRobot.jsx

Dron explorador autónomo cibernético (SCOUT_BOT) que realiza una animación de patrullaje horizontal de 18 segundos sobre la sección de biografía.

3.4 About.jsx

Panel interactivo de biografía con emulador de editor de código y tres pestañas seleccionables:

  • profile.json: Metadatos de contacto, formación y rol.
  • philosophy.js: Declaración de principios de código limpio y arquitectura DRY/SOLID.
  • learning.log: Hoja de ruta del bootcamp (+600h) hacia Full Stack.

3.5 TechStack.jsx

Matriz tecnológica dividida en cuatro cuadrantes interactivos:

React 19 / 18 JavaScript ES6+ Tailwind CSS Figma & Stitch Vitest & RTL Node.js & Express PostgreSQL Google Gemini API

3.6 Projects.jsx

Rejilla interactiva con soporte híbrido para tarjetas con vídeo de alta resolución y capturas optimizadas, badges de tecnologías y enlaces directos a demos en Vercel y repositorios en GitHub.

3.7 CvSection.jsx

Sección dedicada al Curriculum Vitae con visor embebido de patri-aparicio-cv.pdf, controles de ampliación a pantalla completa y botón de descarga directa del documento.

3.8 PortfolioAssistant.jsx

Chatbot conversacional flotante (**Patri AI**) con preguntas predefinidas en diseño flexible (flex-wrap), indicador de escritura en tiempo real y fallback offline garantizado.

4. Ecosistema de APIs, Microservicios y Google Gemini

4.1 Endpoint REST: POST /api/chat

El servidor Express en server/index.js expone la ruta para procesar las consultas mediante el modelo gemini-2.5-flash:

POST /api/chat HTTP/1.1
Host: localhost:5000
Content-Type: application/json

{
  "message": "¿Qué formación y experiencia tiene Patri?",
  "history": [],
  "cvText": "PATRICIA APARICIO DÍAZ...\nPerfil: Frontend Junior..."
}

4.2 Motor de Smart Fallback Local

Si la aplicación se encuentra en un entorno estático o el servidor backend experimenta desconexión, src/services/api.js activa de forma instantánea el analizador semántico offline para dar respuesta inmediata sobre:

  • Identidad y presentación profesional.
  • Stack tecnológico y herramientas.
  • Proyectos realizados y enlaces funcionales.
  • Disponibilidad inmediata para contratación (remoto / Sevilla).

5. Estrategia y Guía de Testing Automatizado

El proyecto implementa una suite completa de pruebas unitarias y de integración utilizando Vitest y React Testing Library:

Archivos de Prueba:

  1. src/tests/portfolioData.test.js: Valida que los datos oficiales de Patri Aparicio, proyectos, skills y preguntas frecuentes existan y cumplan el esquema definido.
  2. src/tests/api.test.js: Evalúa el correcto funcionamiento del cliente HTTP, el motor de respaldo inteligente offline y la llamada al servicio meteorológico.
  3. src/tests/components.test.jsx: Comprueba el renderizado, accesibilidad y montaje de los componentes UI (HeroRobot, ApiWidget).
# Comandos de ejecución:
npm run test     # Ejecución única para CI/CD
npx vitest       # Modo interactivo en desarrollo

6. Guía de Despliegue y Puesta en Producción

6.1 Despliegue del Frontend en Vercel

  • Framework Preset: Vite
  • Build Command: npm run build
  • Output Directory: dist
  • Reglas de Enrutamiento SPA: Archivo vercel.json con reescritura total a /index.html para evitar errores 404 al recargar rutas internas.

6.2 Despliegue del Backend en Render

  • Tipo de Servicio: Web Service (Node.js)
  • Root Directory: server
  • Start Command: node index.js
  • Variables de Entorno: PORT=5000, GEMINI_API_KEY=tu_clave_gemini
