### `[-O_O-] AI_UNIT // SYSTEM OVERVIEW`

Portafolio web personal de desarrollo fullstack diseñado con una estética inmersiva de **terminal hacker / cyberpunk**. Cuenta con componentes interactivos avanzados en tiempo real, widgets asíncronos y una experiencia de usuario orientada a la ingeniería de software limpia, sin rodeos y con un rendimiento optimizado mediante **Vite**.

---

### 🕹️ Características Principales y Arquitectura

- **`[ 🟡 PacMan_Navbar ]`**: Barra de navegación superior interactiva que incorpora la animación clásica del devorador de puntos recorriendo el layout junto a indicadores de telemetría de red.
- **`[ 🤖 AI_Robot_Unit ]`**: Unidades centinela autónomas con animación de patrullaje lateral (`@keyframes patrolRobot`) integradas en la interfaz para simular el análisis del código fuente.
- **`[ 📼 Project_Drives ]`**: Tarjetas de proyectos expandidas con previsualizaciones de vídeo en bucle automático (`autoplay`, `loop`, `muted`, `playsInline`) que muestran demostraciones reales de cada desarrollo.
- **`[ ⚡ Auto_Quotes_API ]`**: Widget asíncrono en bucle de 10 segundos que gestiona un flujo dinámico de sentencias de programación y desarrollo de software.

---

### 💻 Stack Tecnológico

```bash
├── Frontend Core: React, Vite, JavaScript (ES6+)
├── Estilos y UI: Tailwind CSS, Custom Terminal Aesthetics, CSS Variables
├── Control de Versiones: Git & GitHub
├── Despliegue: Vercel (Producción)
└── Multimedia y Conectividad: REST APIs (Weather & Dev Quotes), HTML5 Video Assets

```
🔌 ¿Cómo funcionan las APIs en el Portafolio?
El sistema integra conectividad con servicios externos y flujos asíncronos en dos vertientes principales:

API de Frases de Desarrollo (Quotes Stream):

Utiliza hooks de React (useState y useEffect) combinados con temporizadores (setInterval) para consultar de forma autónoma un array de sentencias de código cada 10 segundos. Simula un flujo de terminal con opción de forzar un refresco manual instantáneo mediante el botón interactivo del componente.

APIs del Clima (Weather Data Integration):

Integradas en los proyectos interactivos (Valhalla del Chatarrero y Proyecto Buhardilla), permiten consultar condiciones meteorológicas en tiempo real para modificar dinámicamente los estados atmosféricos visuales de las interfaces.

⚙️ Guía de Instalación y Clonación Local
Para poner en marcha este repositorio en tu máquina local de forma rápida y limpia, ejecuta los siguientes comandos en tu terminal:

Clonar el repositorio:
git clone [https://github.com/apariciodiazpatricia-cell/patricia-aparicio-dev.git](https://github.com/apariciodiazpatricia-cell/patricia-aparicio-dev.git)

Entrar en el directorio:

cd patricia-aparicio-dev
Instalar dependencias:

npm install
Ejecutar servidor de desarrollo local:

npm run dev
(La terminal te devolverá el enlace local, normalmente http://localhost:5173, con recarga en caliente).

Compilar para producción (Build):

Bash
npm run build
